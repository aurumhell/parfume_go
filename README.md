# ODORIS — интернет-магазин парфюмерии

Учебный проект интернет-магазина оригинальной и нишевой парфюмерии. Серверная часть написана на Go, интерфейс — HTML, CSS и Vanilla JavaScript.

## Запуск

Требуется Go 1.22 или новее.

```bash
go run ./cmd/parfume_go
```

После запуска откройте <http://localhost:8080>. Порт можно изменить переменной окружения `ADDR`, например `ADDR=:9000`.

Проверка проекта:

```bash
go test ./...
```

## Возможности

- главная страница с витриной, преимуществами, отзывами и подпиской;
- каталог и отдельная страница новинок;
- поиск по названию, бренду, описанию и метке товара;
- избранное и корзина с хранением в браузере (`localStorage`);
- оформление заказа с проверкой контактов и способа доставки, сохранение заявки в `data/orders.csv`;
- демонстрационный профиль с локальным сохранением имени и электронной почты;
- страницы «О нас» и «Доставка»;
- подписка с проверкой адреса и согласия, запись контакта в `data/subscribers.csv`;
- адаптивное боковое меню и мобильная версия.

## Изображения

Фотографии ароматов, баннер, иконка сайта используются из публичного репозитория [aurumhell/Odoris](https://github.com/aurumhell/Odoris) через `raw.githubusercontent.com`. Для отображения изображений браузеру требуется подключение к интернету.

## Структура

```text
cmd/parfume_go/       Go-сервер и тесты
web/templates/        HTML-шаблоны
web/static/           CSS и JavaScript
data/                 локальные CSV заказов и подписок (создаются автоматически)
```

## Бизнес-процессы

1. Управление каталогом и карточками ароматов.
2. Поиск и выбор товара.
3. Добавление товаров в избранное и корзину.
4. Оформление заказа: проверка контактов, состава корзины и способа доставки, сохранение заявки.
5. Информирование клиентов о новинках и акциях.
6. Предоставление информации о доставке и сервисе.

**Примечание:** онлайн-эквайринг и интеграция со службой доставки не подключены. Заказ сохраняется локально в CSV и оформляется с оплатой при получении. Корзина и избранное работают в браузере, профиль является демонстрационным локальным разделом.
