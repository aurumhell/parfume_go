# ODORIS — интернет-магазин парфюмерии на Go + SQLite

Проект использует Go для серверной части, HTML-шаблоны для страниц, CSS/JavaScript для интерфейса и SQLite для хранения данных.

## Запуск в GoLand

1. Откройте папку `parfume_go` в GoLand.
2. Убедитесь, что установлен Go 1.22 или новее.
3. Дождитесь загрузки Go-модуля `modernc.org/sqlite` (при первом запуске требуется интернет).
4. Запустите конфигурацию `Go Build` для пакета `./cmd/parfume_go` либо выполните команду из корня проекта:

```bash
go run ./cmd/parfume_go
```

Откройте <http://localhost:8080>.

Проверка:

```bash
go test ./...
```

## Где находится база

По умолчанию Go создаёт файл `data/odoris.db` автоматически. Таблицы и начальные данные создаются при первом запуске из `cmd/parfume_go/schema.sql`. В ZIP также вложена начальная база `data/odoris.db` с товарами и контентом сайта.

Можно указать другой файл базы данных переменной окружения:

```bash
DB_PATH=data/local.db go run ./cmd/parfume_go
```

Порт HTTP-сервера можно изменить:

```bash
ADDR=:9000 go run ./cmd/parfume_go
```

## Что хранится в SQLite

- `products` — товары, бренды, описания, цены, изображения и признак новинки;
- `navigation_items` — меню сайта;
- `advantages` — преимущества магазина;
- `pages` и `page_points` — тексты страниц «О нас» и «Доставка» и их информационные блоки;
- `reviews` — отзывы на главной странице;
- `site_settings` — заголовки, описания, подписи и контактный текст;
- `orders` и `order_items` — заказы и состав заказов;
- `subscribers` — подписки на рассылку;
- `browser_sessions`, `cart_items`, `favorite_items`, `profiles` — корзина, избранное и контактные данные браузерной сессии.

Go запрашивает содержимое из SQLite при формировании страниц. Формы заказов и подписки записывают данные в SQLite. Корзина, избранное и профиль хранятся на сервере в привязке к случайной HttpOnly-cookie-сессии; регистрация не требуется.

## Перенос данных из предыдущей версии

При старте приложение автоматически попробует импортировать `data/subscribers.csv` и `data/orders.csv`, если эти файлы остались от предыдущей версии. Импорт идемпотентный: повторный запуск не создаёт повторные записи. Старые CSV-файлы не удаляются.

Перед полной заменой старого проекта всё равно сохраните копию папки `data`, чтобы не потерять локальные заказы и подписки.

## Как редактировать контент

Для просмотра и изменения данных используйте любой SQLite-редактор (например, Database/SQLite в GoLand или DB Browser for SQLite). Откройте `data/odoris.db` и редактируйте соответствующую таблицу. Например, цена и название товара находятся в `products`, текст главной страницы — в `site_settings`, отзывы — в `reviews`.

`schema.sql` создаёт структуру и первоначальные записи через `INSERT OR IGNORE`; поэтому изменения в существующей базе не перезаписываются при каждом старте.

## Структура

```text
cmd/parfume_go/
  main.go       Go HTTP-сервер, SQL-запросы и API пользовательской сессии
  main_test.go  тесты маршрутов, каталога, заказа и сохранения состояния
  schema.sql    схема SQLite и начальное наполнение
web/templates/ HTML-шаблоны сайта
web/static/    CSS и JavaScript
 data/         файл SQLite создаётся автоматически
```

Изображения и веб-шрифты сайта по-прежнему загружаются из публичных URL, поэтому для их отображения нужен интернет.

Онлайн-эквайринг и интеграция со службой доставки не подключены. Заказы сохраняются в базе и требуют подтверждения менеджером.
